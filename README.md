# Python Fundamentals with AI Assistance

An academic practical laboratory project demonstrating fundamental Python structures, environment setups, and version control best practices.

## 🚀 Projects Included
1. **Factorial Calculator:** An iterative mathematical algorithm computing factorials for non-negative integers.
2. **Fibonacci Sequence Generator:** A loop-driven algorithm producing consecutive Fibonacci numbers up to N entries.
3. **C Structure Translator:** Mapping static low-level C structural paradigms directly into dynamic Python dictionaries.

## 🛠️ Environment and Technologies
* **Development Environment:** Google Colab
* **Version Control:** GitHub
* **Language Integration:** Python 3.x
* **AI Tooling:** Google Colab AI Coding Companion

## 📈 Learning Outcomes
* Developed proficiency with Google Colab notebooks.
* Evaluated technical architecture discrepancies between C and Python languages.
* Synthesized AI-generated version tracking with custom human commit patterns.
